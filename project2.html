Video App Blueprint

About this project

This project is a blueprint, or wireframe, for a video-sharing app inspired by YouTube. The sketch shows where the videos, profile pictures, menu and navigation buttons could go. It is a design plan for an app.

What I learned

I practised planning a screen before starting to code. The wireframe helped me think about how to organise the content and make the app easy to use.
